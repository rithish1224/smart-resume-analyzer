Backend Engineer (Python)
Northwind Cloud, Remote / Hybrid

About the role
Northwind Cloud builds analytics tools for logistics companies. We are hiring a Backend Engineer to design, build, and operate the APIs and data services behind our customer dashboards. You will work with a small team of engineers and data scientists, own services end to end, and help us serve machine learning models reliably in production.

Responsibilities
- Design and build REST APIs and backend services in Python.
- Model data and write efficient SQL queries against PostgreSQL.
- Package services with Docker and deploy them on AWS.
- Write automated tests and maintain CI/CD pipelines.
- Monitor services in production, debug incidents, and improve performance.
- Review code, document designs, and mentor junior engineers.
- Work with data scientists to expose machine learning models through APIs.

Required qualifications
- 3+ years of professional experience building backend services in Python.
- Hands-on experience with FastAPI or Flask.
- Strong SQL skills, preferably PostgreSQL.
- Experience with Docker and containerized deployments.
- Working knowledge of AWS (EC2, S3, RDS, Lambda).
- Solid understanding of REST API design, authentication, and testing.
- Experience with Git and CI/CD workflows.
- Bachelor's degree in Computer Science, Engineering, or a related field, or equivalent practical experience.

Preferred qualifications
- Kubernetes and infrastructure as code (Terraform).
- Redis or other caching and queue systems.
- Experience serving machine learning models in production.
- AWS certification.
- Experience in a startup or small-team environment.

What we offer
Competitive salary, flexible hours, a learning budget, and the chance to shape our platform architecture from the ground up.
